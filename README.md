# Python Terminal Games

A collection of text-based games built in Python built for CMSC 201 by Sadia Rahman, showcasing core programming concepts such as recursion, control flow, and game logic.

## Games Included

### Demogorgon Survival RPG

A survival game where you manage health, inventory, and decisions while being hunted by a Demogorgon. Survive long enough or travel far enough to win.

### Connect Four

A terminal-based version of the classic Connect Four game. Play against another player or a computer and connect four pieces in a row.

### Sudoku

A playable Sudoku game with a built-in solver using backtracking. Load puzzles, make moves, undo, and validate solutions.
